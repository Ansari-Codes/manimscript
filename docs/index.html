03 / LANGUAGE SURFACESMALL SET OF SCENE PRIMITIVES

Describe the
important parts.

Objects establish what exists. Commands establish what changes. Scenes provide the sequence.

◈
DECLARATION / 01

Objects

Named Manim mobjects, created from built-in primitives or external SVG/image assets.

OBJECTS:
    dot: { object: { type:
        "circle", radius: 0.3 } }
▤
CONTAINER / 02

Scenes

A named scene compiles to a Python Scene class with a construct method.

SCENE "Motion":
    PLACE dot AT (0, 0);
⇢
ANIMATION / 03

Commands

Place, move, fade, rotate, scale, transform, wait, or circulate objects.

MOVE dot TO (3, 0)
    FOR 2 RATE LINEAR;
⫸
COMPOSITION / 04

Parallel groups

Start multiple animations together in one zero-lag animation group.

ALL DO:
    MOVE sun TO (-3, 1) FOR 2;
    MOVE moon TO (3, 1) FOR 2;
♫
AUDIO / 05

Voice-over

Synthesize narration with gTTS and line up indented scene actions as it plays.

SPEAK "Let's move." DO:
    MOVE dot TO (1, 0) FOR 2;
